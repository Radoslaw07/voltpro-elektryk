# VOLTPRO Inżynieria Elektryczna – Strona Internetowa

Nowoczesna, responsywna strona internetowa dla firmy świadczącej usługi elektryczne (instalacje, prefabrykacja rozdzielnic, pomiary odbiorcze SEP E1+D1, stacje ładowania Wallbox EV oraz pogotowie elektryczne 24/7).

## Zawartość projektu
- `index.html` – główna struktura strony (Hero, Oferta, Galeria realizacji z filtrami, Kwalifikacje SEP, Obszar działania z mapą, Współpraca, Opinie, FAQ, Formularz wyceny z kalkulatorem)
- `styles.css` – arkusz stylów i responsywny układ
- `app.js` – interaktywne filtry galerii, okno modalne, wyszukiwarka stref dojazdu, akordeon FAQ oraz kalkulator wyceny na żywo
- `img/` – lokalne fotografie zrealizowanych prac elektrycznych

## Publikacja przez GitHub Pages
Strona jest gotowa do natychmiastowego działania na **GitHub Pages** z gałęzi `main` (katalog `/ (root)`).
